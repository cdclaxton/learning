#AI 

- Assembly line of LLMs and Python functions
- Use when the LLM is to do a small number of tasks (i.e. not to be multipurpose)
- Steps of the plan are executed with deterministic code in the required sequence
- Each LLM on the assembly line has a single focus (helps it not be distracted)
- Could use an LLM to direct a user's request to one of a number of agentic workflows
- May be able to run LLMs using parallelism or concurrency
