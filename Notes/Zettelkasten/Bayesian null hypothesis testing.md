#Bayesian 

- Estimation approach using the [[Region of practical equivalence]]
- Model comparison approach:
	- Compute Bayes factor for a model with a spike at the null value and for a model with a broad distribution (e.g. a Haldane prior). However, the Bayes factor is very sensitive to the choice of prior and this approach can accept the null with poor precision (i.e. wide posterior)
	- Both priors need to be meaningful
