#ML #Bayesian 

- Posterior distribution has the same form as the prior distribution $p(\theta)$
- Prior is conjugate only with respect to a particular likelihood function
- Desirable if the denominator in Bayes' theorem is analytically tractable
- Only simple likelihood functions have conjugate priors
- Not all prior knowledge can be expressed in the form of a conjugate prior
- Use [[Metropolis algorithm]] as an alternative
