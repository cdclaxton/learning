#ML 

- Neurons in the context layer remember the previous hidden layer states
- Stored values are delayed by one time step
- Information flow is multi-directional
- Enables it to learn sequences (time-dependent patterns)
- Used for classification, stochastic sequence modelling and associative memory tasks

Elman [[Neural network]]:
- One or more context layers

Jordan neural network
- Similar to Elman networks
- Context neurons are fed from the output layer instead of the hidden layer
