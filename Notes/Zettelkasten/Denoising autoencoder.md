#ML 

- Type of [[Neural network]]
- Contains three layers: input; hidden; and output.
- DA adds noise randomly to the input during training
- Stochastic variant of the [[Autoencoder]]
- Noise prevents the hidden layer from learning the identity function so it learns more robust features

**Random masking**
- Randomly forces a fraction of the input attributes to 0 or 1 (salt and pepper noise)

**Stacked denoising autoencoder** is composed of multiple DAs
