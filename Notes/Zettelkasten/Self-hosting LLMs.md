#AI

Use an open-source [[LLM]] with tools like Ollama
- **Open source** -- access source code and training data
- **Open weight** 

Pros:
* Privacy
* Open-source and open-weight models can be fine-tuned (customised)

Cons:
* Setup and maintenance (MLOps)
* Need to use GPUs (able to perform many calculations in parallel than CPUs) as CPUs are too slow
